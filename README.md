# 🐦 Adventurous Bird Game

Welcome to the official repository of my first programming project! This is a dynamic adventure game built to demonstrate clean logical programming, source code organization, and structural outputs.

🔗 **[Click here to play and experience the game live in your browser](https://extraordinary-brioche-c51a33.netlify.app/)**

---

## 🚀 Features

* **🎮 Responsive Controls:** Fully optimized for seamless inputs and smooth character movement.
* **⚡ Instant Updates:** Lightweight environment ensuring real-time screen updates without latency.
* **🎯 High Interactivity:** Features dedicated states for the starting interface, obstacle dodging, and immediate outcome screens.

---

## 🛠️ Built With

* **Language:** C# (.NET Core) / HTML5 & JavaScript for the web version
* **Methodology:** Object-Oriented Programming (OOP) principles
* **Deployment:** Netlify & GitHub
